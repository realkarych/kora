# Usage and pricing source evidence

Checked 2026-10-23 for [issue #142](https://github.com/realkarych/kora/issues/142). This record distinguishes source inspection from runtime observations. It records no new live model calls, adapter conformance run or performance measurement. The normative contract is [data-model section 7](../specs/data-model.md#7-usage-records-and-completeness-fr-91); its implementation remains pending.

## Claude

The [October 19 probe](claude-agent-sdk-probe-2026-10-19.md#usage-report) observed per-call final stream counts, initial assistant snapshots and cumulative per-model results separately. Output included thinking; input excluded separate cache-read/write counts. Its repeated-query example establishes that result model totals cannot be added to per-query totals. It did not exercise resume, subagent usage or streaming interruption.

The [official SDK cost guide](https://code.claude.com/docs/en/agent-sdk/cost-tracking) describes per-model `model_usage`/`costUSD`, cumulative resumed costs and message-id deduplication. It also distinguishes main-loop query usage from whole-tree model totals when subagents run. Those scopes must agree before a query-wide cache split can enrich a model row; a single model name alone does not prove matching coverage. Native USD is an estimate, not a billing statement. The existing probe's numeric cost on subscription authentication is not evidence that a subscription is USD-billable.

The accepted adapter mapping retains the latest per-call stream counts, never sums assistant snapshots or deltas, and normalizes a supported final per-model cost into `reported_usd`. Query-wide cache TTL counts are used only with proven matching attribution. Unknown basis values remain evidence and use the declared table mapping; no whole-process amount is distributed among models. Missing dimensions, post-result tails and observation loss remain explicit. Real subagent forwarding, resume and streaming-abort behavior require separate adapter evidence.

The pinned Python SDK declares [`ModelUsage.costUSD` as `float`](https://github.com/anthropics/claude-agent-sdk-python/blob/v0.2.168/src/claude_agent_sdk/types.py). Its [transport](https://github.com/anthropics/claude-agent-sdk-python/blob/v0.2.168/src/claude_agent_sdk/_internal/transport/subprocess_cli.py) uses ordinary JSON decoding, and the [message parser](https://github.com/anthropics/claude-agent-sdk-python/blob/v0.2.168/src/claude_agent_sdk/_internal/message_parser.py) forwards model usage. The adapter therefore cannot recover the original decimal wire precision through that interface. The native-ingress normalization rule preserves the SDK estimate as a bounded decimal string; exact decimal-only processing starts at the normalized boundary. No alternate CLI parser is implied.

The [OpenAI prompt-caching guide](https://developers.openai.com/api/docs/guides/prompt-caching) places cache reads and writes inside total input and treats their rates as alternatives to ordinary input pricing. Thus uncached input subtracts both. Its cache lifetimes differ from the Claude 5-minute/1-hour fields: the adapter must not relabel one provider's TTL as another's. Missing supported split/rate evidence leaves the price unknown. The [reasoning guide](https://developers.openai.com/api/docs/guides/reasoning) includes reasoning within output usage and bills it as output; adding it again double-counts.

These sources establish carriers and inclusion rules, not notification timing, complete model attribution, lossless delivery, actual rerouting or kill behavior in kora. Work item 15 owns deterministic real app-server-driver tests and separate operator probes. Replay checks normalization and duplication only. Without usable pre-kill usage the result is unavailable; with it, partial. Completion status and synthetic totals do not repair missing evidence. Source upgrades require rechecking the mapping; CI must not call real model providers.
