# Fan-out declared type validation evidence

Date: 2026-10-30. Implementing [issue #503](https://github.com/realkarych/kora/issues/503), a scoped part of MVP work item 3. Commands, tested revisions, environments, CI artifacts and independent results belong to the PR.

## Delivered boundary

`validate_fan_out_types` accepts a structurally validated `GraphDocument` whose caller-owned maps remain unchanged during the synchronous call. One saved ancestry index serves root nodes and every stored body's nodes, including unused/shared/nested definitions. The pass visits stored declarations without expanding invocations. Only fan-out nodes have obligations.

`over` resolves only in the node's own input map. The iterative parser establishes its declared shape and valid saved base ancestry before rejecting a scalar with fixed IR004. Upstream producer resolution, reserved sources and selected paths do not change this local declaration check. Each output resolves its named body export and compares the export's declared base and depth with the output: exactly one extra list level and saved base covariance are required. A narrower internal producer cannot bypass the exported interface. Fixed IR003 reports known collection incompatibility.

Missing input/body/export/collect names, malformed spelling or invalid/unknown ancestry remain unresolved, including equal unknown names and unequal depths. Link and declaration passes retain diagnostic ownership; independent known failures continue without waiting for a globally successful prerequisite pass. Results count visited nodes/definitions/fan-outs/outputs, contract entries, indexed types and checked/unresolved obligations. Checked plus unresolved mapped inputs equals visited fan-outs; compared plus unresolved collections equals visited collection outputs. Scoped validity is not full graph or execution admission.

Diagnostics carry only fixed messages, safe declaration paths, the fan-out node ID and that node's revalidated source. Unsafe sources have no body/graph/producer fallback. The existing collector owns copied bounded results; the existing logger owns its queue/writer. The pass owns the temporary ancestry index, checker and parsed shapes, with no persistent cache, thread, task, descriptor, transaction or process. Finite synchronous return and unchanged logger shutdown define release; no new cancellation/interruption guarantee is introduced.

No authored field, schema, behavior binding, registry alias or payload is evaluated or changed. Ordinary wrapper input/output mapping, upstream/path typing, effective-schema evaluation, aggregate admission/materialization and runtime fan-out ordering/expansion/settlement remain outside this change. Runtime gate #71, ADR-0027 and artifact aggregate gates stay active. No dependency, persisted format, package layer, public API/CLI/MCP operation or execution authority changes. Those unchanged boundaries stop review propagation into databases, providers, scheduler and public clients.

## Diagnostic method and limits

`test_fan_out_type_resource_observations` records the existing Report/Sample format in JUnit property `fan_out_type_resources`. Nine workloads cover 1/1,000 fan-outs, 1,000 outputs on one node, depth-5,000 ancestry, 1,000 invalid-ancestry declarations, 1,000 calls sharing one stored fan-out, 1,000 stored bodies, 100 depth-2,000 collection types and 3,000 collection mismatches. One warm-up and three untraced timings per workload produce 27 samples. Six mixed post-GC batches record settled traced memory and cumulative peaks; RSS is recorded where available. Construction and traced timing are excluded. Local observations run separately from other local checks. Hosted contention and recorder/runtime allocation remain limitations.

Exact counters, collector capacities and reference release are blocking. Time, process-wide heap/RSS and cumulative peak are diagnostic, with no pass threshold, percentile, convergence, general leak-freedom or operational-envelope claim. Work includes one ancestry index, every stored node and fan-out output, and every parsed endpoint spelling, including repeated shared export spellings. Counters do not count characters or every machine operation. Temporary storage includes the index, current shapes/base strings and bounded collector.

A demonstrated contract defect, retained owned resource or material unexplained growth triggers bounded investigation. Diagnostic outliers alone add no campaign or merge gate.
