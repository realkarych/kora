# Effective StructuredOutput composition

Implementation record for #1594, checked on 2026-11-15 against the accepted [standard-schema contract](../specs/schema-validation.md) and [ADR-0027](../../docs/decisions/0027-bounded-effective-schema-validation.md). This pure synchronous composition supplies complete validity and extraction, without activating a saved writer/reader, artifact acceptance or scheduler settlement.

## Authority and operation

The caller owns authenticity and stable detached resolved type/source records. The IR helper checks exact v2 policy, native shape, ancestry, original references, complete selected closure and original source/checker roles. It preserves document order and equal-but-distinct roots. Parent/declared/inline documents become constraints in that order; reference-only documents remain support resources. The complete StructuredOutput revision descriptor is checked without filesystem access. Unknown policies, unsupported schema and capacity exhaustion remain fixed refusals; a descriptor mismatch preserves SO005.

Installation supplies a trusted map keyed by validation/digest/summary role and immutable identity. Composition looks up only required identities, validates each binding kind and captures callables before value work. It does not enumerate or retain the original map. The generic schema identity requires the fixed common-evaluator marker, preventing a stock numeric validator from rejecting first. Every non-schema ancestor behavior is required. Inherited extraction identities must be available; only the declared ones are retained for extraction. The builtin map factory consumes the concrete StructuredOutput provider whose constructor already checked its frozen catalogue binding. No claimed saved name loads code.

The frozen model admits raw/native input. Each validation hook receives an isolated detached export, released before the next hook. The schema operation then obtains one private checked native tree and the complete decoded source. It applies the existing exact common evaluator once over every constraint. A schema mismatch has fixed root SO006; model-invalid preserves SO001–SO005; a non-schema behavior mismatch carries no copied provider diagnostics. Only complete validity returns the immutable canonical model and captured declared extraction callables. Each extraction gets another isolated export. Arbitrary custom results transfer under the existing ArtifactType ABI without an additional composition copy or cache; the receiving consumer owns applicable result admission/retention. Trusted providers remain cooperative code.

A value admitted by the frozen model may exceed a v2 shape limit; it then refuses before numerical-view or library construction, without changing original model admission order.

## Evidence and limits

Focused cases cover exact policy ordering, native refusal before indexed work, parent/reference completeness and cycles, original roles/metadata, reference-only non-assertions, equal roots, generic exact arithmetic, every constraint, preserved raw/native model errors, unknown installed identities and immutable capture. Hook mutation tests use actual protocol implementations from the conformance fixtures; existing conformance continues to reject input-mutating providers.
