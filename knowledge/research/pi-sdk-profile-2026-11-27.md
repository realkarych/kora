## Tools and process ownership

The SDK supports custom tool definitions. Its agent loop validates tool arguments and calls the selected definition's execute callback. A start event can precede successful preparation. The active tool list, callable list and full tool information are separately inspectable. Register only reviewed callback definitions and prove that an allow reaches the intended effect while invalid, missing and late decisions leave the filesystem unchanged. A matching tool name alone cannot distinguish a kora callback from an unwrapped native implementation. [SDK tools](https://github.com/earendil-works/pi/blob/ef4a1cfcca62b77ad3558337ff3e1c7f6beeadfe/packages/coding-agent/src/core/agent-session.ts) · [Agent loop](https://github.com/earendil-works/pi/blob/ef4a1cfcca62b77ad3558337ff3e1c7f6beeadfe/packages/agent/src/agent-loop.ts)

Native path utilities strip a leading `@`, normalize Unicode spaces and resolve paths for tools. Test the exact effective target when evaluating Policy and when applying a file operation. The normal Bash route spawns a detached group on POSIX and its output accumulator can spill the full output to a temporary file. The SDK's cooperative process-tree cleanup does not establish reaping after forced termination of the SDK itself. The designed shell route delegates launch, output and cleanup to the runtime owner. Confirm real abort, kill, descendant release, bounded pipe/temporary data and honest unresolved closure through that route. [Path utilities](https://github.com/earendil-works/pi/blob/ef4a1cfcca62b77ad3558337ff3e1c7f6beeadfe/packages/coding-agent/src/core/tools/path-utils.ts) · [Bash execution](https://github.com/earendil-works/pi/blob/ef4a1cfcca62b77ad3558337ff3e1c7f6beeadfe/packages/coding-agent/src/core/tools/bash.ts) · [Output accumulator](https://github.com/earendil-works/pi/blob/ef4a1cfcca62b77ad3558337ff3e1c7f6beeadfe/packages/coding-agent/src/core/tools/output-accumulator.ts)

## Result, usage and shutdown

Subscribe before sending the prompt. Pi distinguishes an interim agent result from final settlement, which may follow retries and additional work. Assistant messages include model identity, usage and a stop reason. An aggregate session total cannot attribute observed token usage per model, establish an unobserved final value or prove result acceptance. Observe complete and interrupted runs, provider limits and internal retries through the pinned interface. Derive the terminal output candidate only from the corresponding settled run. `abort()` awaits the SDK's work and `dispose()` signals cooperative cleanup. The launcher still accounts for actual resources.
