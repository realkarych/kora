# Complete standard-schema source checking

Implementation record for #1585, checked on 2026-11-15 against the accepted [standard-schema contract](../specs/schema-validation.md) and [ADR-0027](../../docs/decisions/0027-bounded-effective-schema-validation.md). This record describes source checking only. It is not a new numerical policy, publication certificate or evidence for complete native value evaluation #1582.

## Delivered boundary

`standard_schema_policy` binds exact ordered v2 output/parameter policies before source access. `standard_schema_scan` admits exact native JSON, rejects cycles/subclasses/nonfinite numbers/surrogates, and counts full source bytes, occurrences, cardinalities, depth, schema positions and reference occurrences. It measures compact ASCII JSON without materializing an encoded tree. Integer magnitude is checked before decimal formatting. Alias occurrences count again; original container depth is separate from normalized wrappers.

`standard_schema_source` checks direct pinned draft-2020-12 keyword argument shapes and builds original position/reference associations. All supplied documents and schema positions participate, including unchosen branches. Annotation and literal data remain data. Boolean false schemas are supported sources. Unsupported features, ambiguous names, invalid target positions and malformed pointers refuse. Root `$id` cannot rebase local pointers; nested schema `$id` remains unsupported. Saved artifact URNs identify only supplied roots. Both reference keywords retain their separate edges.

`standard_schema_support` admits the existing preparation term before source indexes, argument uniqueness or references. It checks cycles iteratively across all positions and potential call depth from actual constraint roots, without expanding execution trees. Edges retain `once`, `array` or `object` categories; no value-dependent weight is guessed. The operation returns immutable scalar accounting or a fixed refusal after internal state has gone out of scope. The caller still owns its supplied input and any unexpected exception/traceback. Original wire admission, provenance, completeness of selected roles, installed behavior, aggregate slots, cancellation/drain and publication remain composition obligations.

## Work and temporary ownership

Use S for admitted source occurrences, P for schema positions, R for references, D for documents, Sd for source nesting, SA/SM for source array/member maxima, and T for executable containment edges. Each schema position has at most one containment parent, so T < P. The source scan visits bounded occurrences without a copy or full path vector. Wrapper depth adds at most three physical frames to an original document's depth; the accepted fixed traversal allowance covers those frames. The operation creates no numerical views, registry, resolver or library errors.

The accepted source preparation term uses observed source nodes, positions, references, maximum member count and maximum key width. Multiplication saturates at the validation-score limit plus one before indexed work. The initial source scan and sequential text work remain bounded by source bytes/nodes; the score is not an instruction counter or latency guarantee.

String-array duplicate checking uses a fixed 21-bit most-significant-bit partition over Unicode codepoint plus one, with zero as end-of-string. A character participates in at most 21 partition passes at its depth. Disjoint pending groups contain at least two strings each. The algorithm keeps n copied-reference slots and at most floor(n/2) pending fixed records plus their slots: at most 2n logical entries, within 2*SA. It does not copy string contents or mutate the input. Required/type/dependency arrays are checked sequentially, so their scratch does not accumulate.

| Accepted allocation | Source implementation ownership |
|---|---|
| `4*S` | The borrowed original/normalized occurrence tree remains charged under both source roles even when identical. No extra snapshot, canonical byte string, literal tree or numerical tree is constructed by this source operation. The remaining two tree allowances are unused here. |
| `12*P` | P Site records and P list slots; at most P fixed index-key tuples and P map rows; containment edges use at most 2T tuple/slot entries; graph reverse adjacency uses P outer slots and T parent slots; ready queue uses at most P slots. This is at most 10P, including indexes retained during graph checking. Site fields contain scalar associations/depth/remaining counts; variable edge lists are counted separately. |
| `8*R + 4*D` | Each reference uses a fixed key tuple plus a map row, an edge tuple plus its slot, and one reverse parent slot: 5R. Document roots and named-root map rows use at most 2D. Constraint indexes are borrowed from the already charged source list; repeated roots do not create another role vector. |
| Fixed traversal records | Source scan, schema-position recursion, keyword checks, generators, fixed tuple arguments and graph counters stay within `256*(Sd+1)`, without borrowing resolver or value-frame allowances. Source recursion is bounded by JSON depth, not by a potentially long reference chain. |
| Source scratch | Duplicate-array scratch is at most `2*SA`; fixed iteration records stay in the traversal allowance. No authored-sized path, split-token list, recursive error context or sorted key collection is built. |

These source allocations together are below the accepted 1,048,576-entry maximum at the source maxima: `4*16384 + 12*2048 + 8*4096 + 4*64 + 256*(32+1) + 2*4096 = 139776`. This is a conservative bound on the structures this operation owns, not the complete value-dependent ledger or an executable certificate for a future value. #1582 must reconcile the entire simultaneous ownership before evaluation; unused entries in one row never justify a structure belonging to another.

Pointer decoding first validates the closed ASCII fragment grammar, then writes decoded octets into one bytearray whose initial length is at most the source-string byte capacity. Strict native UTF-8 decoding rejects malformed/overlong/surrogate sequences. Pointer tokens are visited one at a time with bounded slices/replacements and exact array-index checks. It never calls `urllib` or a registry and never constructs a list proportional to the number of separators or percent escapes. Temporary decoded text, token slices, replacements and buffer resize overlap fit a conservative 32 times the admitted per-string bound; named URN construction adds at most eight times complete source bytes plus 128 bytes per document. With two admitted original/normalized source-byte charges and bounded integer formatting, the source-only variable storage is below 16 MiB at the fixed capacities, inside the accepted 256 MiB bound. Python headers, allocator retention and process RSS are not inferred from this calculation.

The preparation graph stores indexes, not object references between Site records; no ownership cycle is introduced. Ordinary `SchemaRefused` exceptions carry only a fixed reason and are handled inside the entry point; their traceback ownership is discarded before completion diagnostics. No forced collection, cache flush, global patch or background cleaner supplies release. Unexpected exceptions propagate to the caller's existing safe-failure owner and do not produce a successful completion event.

## Evidence and limits

The focused modules cover exact bindings, every selected source, closed pointers and both references, direct argument semantics, native domains, shape/preparation bounds, hidden cycles, original depth, ordinary release and diagnostics. The ownership test observes live radix and graph containers through a test-only profiler and retains scalar maxima only; it restores the prior profiler in `finally`. Its observations verify the named logical allocations, not elapsed time or process memory. The source mapping above provides the structural upper bound beyond the exercised fixture.

`test_standard_schema_source_releases_owned_state` compares actual input reference counts after success and each ordinary refusal family and checks that URL-parser cache statistics are unchanged. `test_standard_schema_source_refusal_drops_exception_frames_without_collection` observes reclamation of a rejected native object without forced collection. Real diagnostic pipes exercise content exclusion, caller context, DEBUG filtering, queue overflow, broken output and observed writer shutdown. No database is involved.

The reference-occurrence maximum is distinct from support: a source with 2,048 positions and 4,096 reference occurrences passes the native occurrence scan but its cyclic graph refuses. Individual shape ceilings never promise combined support. The [complete native decision record](standard-schema-decision-2026-11-15.md) maps #1582 numerical E/W/Q admission, representation/error ownership and installed-library validation.
